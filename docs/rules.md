# Synthopwars — Rules (pointer)

This file used to duplicate the game rules with numbers that had drifted out of sync with both the code
and `GAME_RULES.md` (different Metadeck size, different Power formula, different win-condition names).
Rather than maintain three copies, the rules now live in one place:

- **Rules of play** (turn structure, combat math, resources, win conditions, keywords): `../GAME_RULES.md`
- **Card system, the 5-axis Character design, and the 9 Characters**: `CARDS.md`

If you're looking for deck-archetype flavor, battlegrounds, or the wider feature list (progression,
social, settings), see `GDD.md` in this folder — that content isn't rules and lives there instead.

*Last reconciled: 2026-07-22, as part of the Character-system redesign.*
